Jarvis Assistant

Личный автоматизированный ассистент для управления бизнес-отчётностью: читает данные из Google Calendar, Google Sheets и Google Docs владельца аккаунта и присылает отчёты в Telegram.

Приложение используется только владельцем аккаунта, не является публичным сервисом и не передаёт данные третьим лицам.
