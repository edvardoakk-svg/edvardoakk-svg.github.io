Политика конфиденциальности

Jarvis Assistant — персональный инструмент автоматизации для одного пользователя (владельца аккаунта). Не является публичным сервисом и не распространяется другим пользователям.

Какие данные используются

Приложение через Google OAuth получает доступ к:

  • Google Calendar — для чтения событий и напоминаний;
  • Google Sheets — для чтения и обновления финансовых таблиц владельца;
  • Google Docs — для чтения и ведения рабочих заметок владельца.

Как используются данные

Данные используются исключительно для формирования автоматических отчётов, которые отправляются владельцу аккаунта в Telegram. Данные не продаются, не передаются третьим лицам и не используются в рекламных целях.

Хранение

Учётные данные авторизации (OAuth-токены) хранятся на приватном сервере, принадлежащем владельцу аккаунта, и не передаются за пределы этого сервера.
